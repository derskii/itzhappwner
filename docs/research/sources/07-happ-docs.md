# S7 — Happ app-management developer docs

- URL: https://www.happ.su/main/dev-docs/app-management.md
- Source type: primary Happ product documentation.
- Scores: credibility 5/5; recency 5/5; bias risk low.
- Verbatim excerpts: “change-user-agent”; “User-Agent used in headers when receiving the subscription.”

The public Happ documentation describes a `change-user-agent` management parameter to alter the request User-Agent. It does not document `x-os`, `x-ver`, `x-device-os`, `x-ver-os`, or `x-device-model` as Happ request requirements or semantics. This absence is a limit of the public docs, not proof Happ never sends device headers.
