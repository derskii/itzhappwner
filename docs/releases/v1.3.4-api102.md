# Happwner 1.3.4-api102

- JSON — формат по умолчанию, в том числе после обновления с 1.3.3. Выбор **JSON / sing-box JSON / URI** расположен на главном экране.
- Исходный JSON сервера сохраняется без удаления DNS, маршрутов и неизвестных приложению полей. Большие JSON и Base64-ответы обрабатываются через файлы.
- Если сервер отдаёт VLESS, VMess, Trojan или Shadowsocks ссылки, режим JSON создаёт JSON Xray. Приложение явно сообщает, что JSON восстановлен из ссылок: отсутствующие в них настройки сервера восстановить невозможно. Исходная ссылка сохраняется в `happwner_source_uri`.
- При смене формата уже загруженный исходный ответ обрабатывается повторно без сетевого запроса. Отключение преобразования перестало оставлять на экране старый список URI.
- Галочки обработки сохраняются сразу. JSON → URI и Xray → sing-box выбирают взаимоисключающие форматы.
- sing-box JSON обрабатывает большие исходные массивы по одному конфигу и объединяет результат. CI проверяет полученный конфиг с 500 серверами командой `sing-box check` версии 1.14.4.
- Кнопка редактирования рядом с HWID открывает короткое окно изменения или генерации. Сохранение обновляет текущий профиль по ID, включая встроенные профили. Одинаковые названия разрешены и не перезаписывают другой профиль. Изменённый HWID сохраняется после переключения профилей.

Ограничения: до 256 МиБ на файл. Для преобразования в sing-box/URI отдельный исходный JSON должен укладываться в 2 097 152 символа и глубину 128; исходный JSON в режиме JSON сохраняется целиком без этого разбора. При объединении sing-box действует бюджет 4 МиБ на суммарное сериализованное представление преобразованных конфигов, а не на размер исходной подписки. Расшифровка ответов с Encrypt-Tag по-прежнему ограничена 4 МиБ; большой исходный зашифрованный ответ можно сохранить. Неподдерживаемый ввод не выдаётся за успешно преобразованный JSON: приложение показывает ошибку и сохраняет исходник.

Подпись APK совпадает с 1.3.3 этого форка: обновление устанавливается поверх него.
