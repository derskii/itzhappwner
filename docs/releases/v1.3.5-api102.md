# Happwner 1.3.5-api102

Исправлена регрессия 1.3.4: подписки с `hysteria2` больше не попадают в добавленный конвертер URI → Xray и не вызывают `Unsupported link protocol`.

- Удалены принудительное построение JSON из ссылок и добавленная кнопка выбора формата.
- При выключенных JSON → URI и Xray → sing-box исходный JSON сохраняется побайтно. Ссылки любого протокола сохраняются без преобразования; смешанные списки не теряют серверы.
- Base64 декодируется по исходной настройке «Base64 в текст». При её отключении оболочка сохраняется. Настройки обработки запроса и Моста независимы, больше не сбрасываются при открытии приложения.
- Удалён добавленный в 1.3.4 заголовок Accept, навязывавший серверу предпочтение JSON. Профиль, User-Agent и HWID продолжают определять запрос как раньше.
- Сохранены потоковая загрузка и импорт, сохранение полного результата в файл, ограниченный предпросмотр и защита от переполнения буфера обмена. Сохранено редактирование HWID в существующем профиле.

Установка поверх 1.3.3/1.3.4: APK подписан тем же ключом; удалять приложение и профили не требуется. После установки повторите запрос кнопкой «Профили». Преобразования остаются только в прежних настройках и выполняются при их включении.

Проверки: регрессия со смешанными VLESS/Hysteria2/TUIC/неизвестными URI в Base64, все восемь сочетаний исходных переключателей, побайтная сохранность JSON, 500 больших JSON общим объёмом более 64 МиБ при 64 МиБ heap в JVM-тестах, отмена и очистка временных файлов, сохранение HWID. Локальные unit tests, Android lint и сборка APK; повторная проверка в GitHub Actions. На физическом телефоне и личной подписке пользователя проверка не проводилась.

Ограничения: файл ответа до 256 МиБ; предпросмотр до 15 000 символов, полный результат сохраняется в файл. Для явной JSON-конвертации один объект ограничен 2 097 152 символами и глубиной 128, объединённый sing-box — 4 МиБ. Расшифровка AES с Encrypt-Tag всё ещё ограничена 4 МиБ; для большего зашифрованного ответа доступно сохранение оригинала. Исходный незашифрованный JSON и его Base64-представление не ограничены 4 МиБ.

Авторы оригинала: Omegaplex, slavrom21. https://github.com/Omegaplexx/Happwner — исходные условия некоммерческого использования сохранены.
