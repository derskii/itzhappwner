# Happwner 1.3.3-api102

Исправления больших подписок и работа с файлами.

- Загрузка HTTP-ответа прямо на диск, без массива размером со всю подписку.
- Преобразование больших JSON-массивов и последовательностей объектов по одному конфигу. Добавлены проверки на 142 JSON и на 500 JSON общим размером более 64 МиБ при Java heap 64 МиБ.
- Исправлено преобразование JSON с переносами строк.
- Кнопки «Открыть подписку из файла» и «Сохранить полностью в файл» в заголовке результата.
- Предпросмотр ограничен 15 000 символами. Полная подписка экспортируется из файла; большая подписка не отправляется через Android Binder в буфер обмена или состояние Activity.
- Локальный HTTP-мост загружает и отдаёт ответ через файлы. Ошибки преобразования возвращают HTTP-ошибку, а не молча обрывают соединение.
- Защита от чрезмерной вложенности JSON и обработка ошибок загрузки, преобразования и файловых операций.

Границы обработки: до 256 МиБ на загружаемый/импортируемый файл; для больших массивов JSON-to-URI обрабатывает отдельные объекты до 2 097 152 символов и глубины 128. Общее число конфигов не ограничено 500. Неподдерживаемые большие форматы, большие зашифрованные ответы и слишком крупные отдельные JSON в приложении сохраняются в исходном виде для экспорта с пояснением. Большой зашифрованный ответ мост отклоняет HTTP 413. Для расшифровки и объединения Xray в Sing-box целиком действует порог 4 МиБ. Нужен свободный объём диска для исходника и результата.

Проверки используют искусственные конфиги. Реальная подписка пользователя и тестирование на его телефоне в эти проверки не входят.

APK этого форка имеет отдельную подпись. Если Android не позволяет обновить установленную сборку, сначала сохраните нужные настройки и удалите старую версию.
